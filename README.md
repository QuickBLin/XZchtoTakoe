# Классификация и маршрутизация обращений в техническую поддержку

Учебный проект по курсу «Интеллектуальные информационные системы». Команда — Масан Влад и Медведев Федор, 4 курс ИБ.

Приложение принимает текст обращения или CSV, определяет одну из шести тем и назначает локальную очередь специалистов либо ручную проверку. Сохраняет историю в SQLite, позволяет исправить очередь, найти похожие учебные обращения и выгрузить журнал. Реальная отправка во внешнюю службу поддержки не реализована.

## Содержимое комплекта

- `app.py`, `triage.py`, `assistant.py` — интерфейс, модель, маршрутизация и помощь оператору.
- `batch.py`, `journal.py`, `route_batch.py` — CSV, SQLite и командный режим.
- `evaluate.py`, `experiment.py`, `research.py` — оценка, сравнение и дополнительное исследование.
- `test_*.py` — 31 программная проверка.
- `data/`, `examples/`, `results/` — данные, примеры, результаты и журналы.
- `evidence/` — 16 реальных снимков и графики.
- `Материалы/` — презентация на 28 слайдах, отчёт Word и PDF на 39 страницах PDF, интерактивный HTML-атлас.
- `docs/` — техническая документация, протоколы, происхождение данных и распределение задач.

## Запуск через VS Code

1. Распакуйте архив и откройте в VS Code папку, содержащую `app.py`.
2. Установите расширение Python от Microsoft. Командой `Python: Select Interpreter` выберите Python с Tkinter и установленными зависимостями. Проверенное окружение — Python 3.13.9, scikit-learn 1.7.2.
3. Для чистого окружения выполните из папки проекта:

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

4. Выберите `.venv/Scripts/python.exe` как интерпретатор VS Code. Для отладки предусмотрена конфигурация F5. Можно запускать `app.py` командой Run Python File in Terminal.

Если библиотеки уже установлены в Anaconda, выберите её `python.exe`. Обычный путь в Windows — `C:\Users\<пользователь>\anaconda3\python.exe`. В PowerShell путь с пробелами запускается через `& "полный путь к python.exe" app.py`.

Также доступен `Запуск Windows.cmd`. Он сначала проверяет готовую Anaconda в стандартной папке пользователя, затем использует или создаёт `.venv` через Python 3.13. Создание окружения требует установленного Python 3.13, установка библиотек — доступа к сети. Скрипт не устанавливает сам Python. При ошибке откройте терминал и прочитайте сообщение.

## Пример использования

В приложении выберите «Доступ к порталу» и нажмите «Распределить и сохранить». Ожидается «Управление доступом». Пример «Неясное обращение» должен попасть на ручную проверку. Выберите строку журнала и нажмите «Разбор заявки» для просмотра вопроса и похожих train-примеров. Для пакета выберите `examples/demo_batch.csv`; повтор того же файла не добавляет заявки. Для отрицательного сценария используйте `examples/rejected_batch.csv`.

База создаётся в `instance/tickets.sqlite3`. Фильтр окна показывает текущую очередь, экспорт содержит весь журнал. Исправление назначения оператором не переобучает модель.

## Повторение проверки

Используйте один и тот же выбранный Python для приложения и команд ниже. Если окружение не активировано, замените `python` на `.\.venv\Scripts\python.exe`.

```powershell
python -m unittest -v test_system test_extended test_assistant
python experiment.py
python research.py
python route_batch.py examples/demo_batch.csv --db instance/demo.sqlite3 --export instance/demo.csv
```

Тесты GUI требуют доступного рабочего стола с Tkinter. `experiment.py` проверяет хеши зафиксированных исходников и настроек. Не изменяйте рабочие пороги по test или stress. Метки и результаты находятся в CSV и JSON; сохранённые прогоны — в `results/run_*.log`.

## Метод и результаты

TF-IDF слов, пар слов и символьных фрагментов 3–5 символов объединяется с логистической регрессией. Модель обучается при запуске на 144 train-примерах. Validation содержит 36, test 60, stress 72; всего 312 синтетических обращений. Базовое сравнение — поиск по ключевым словам.

Рабочие пороги — оценка первой темы не ниже 35% и отрыв от второй не ниже 25 п. п. На test правильных маршрутов 48/60 против 37/60 у словаря, на stress 42/72 против 27/72. На stress верны 22 из 26 автоматических назначений. Проценты модели не калибровались как гарантии правильности.
