# Руководство оператора

## Одна заявка

Оператор переносит описание без служебных секретов и нажимает «Распределить и сохранить». Справа видны исходная очередь, два наиболее высоких класса с оценками, объяснение сработавшего правила, несколько признаков и решение словаря. Запись появляется в журнале. Лидер модели может отображаться даже при ручной очереди. Двойное нажатие на строку раскрывает полный текст.

Ввод должен содержать минимум одну русскую или латинскую букву и до 2000 символов после удаления крайних пробелов. Пустой, цифровой или слишком длинный текст даёт сообщение об ошибке. Текст заявки сохраняется локально. Для репетиции используйте вымышленные тексты.

## Ручная проверка

Выберите «Ручная проверка» в фильтре. Выберите заявку, уточните симптом и переключите очередь в списке под журналом. Нажмите «Изменить очередь». В отфильтрованном списке строка исчезнет, если новая очередь другая. Вернитесь к «Все очереди». «Первоначальная очередь» показывает решение системы, «Текущая очередь» — последнее решение оператора. SQLite хранит также предыдущую и новую очередь в истории изменений.

## Входной CSV

UTF-8 или UTF-8 с BOM, разделитель запятая, заголовок `id,text`. Идентификаторы внутри файла уникальны, длина до 80 символов. Запятая внутри текста и многострочные значения требуют двойных кавычек. Лимиты: 512 КиБ, 500 заявок. Весь файл проверяется до записи. Неисправная строка отменяет импорт целиком и выводит номер строки. Пустой файл после заголовка также отклоняется.

При повторной загрузке идентичных байтов, в том числе под новым именем, возвращается номер старого пакета без дублирования строк. Замена содержимого или переносов строк образует другой файл. ID обозначает строку внутри пакета.

## Выгрузка

Выгрузка содержит внутренний номер записи, время, пакет, внешний номер, текст, класс модели, оценку, первоначальную и текущую очереди. Пустые поля пакета и внешнего номера относятся к индивидуальному вводу. Маршруты выгружаются кодами из `data/README.md`. Выгрузка содержит весь журнал и сохраняется отдельно от SQLite. Запись в файл сначала выполняется временно, затем готовый файл перемещается на выбранный путь.

## Диагностика

| Что видно | Что проверить |
| --- | --- |
| Окно не открывается | Версию Python, установку зависимостей и наличие Tkinter |
| Ошибка UTF-8 | Пересохранить CSV в UTF-8 с запятой |
| «Строка 3» | Посмотреть второй столбец указанной физической строки файла |
| После смены очереди заявка исчезла | Фильтр. Выбрать «Все очереди» |
| Отображается мало строк | Журнал показывает до 100 записей выбранной очереди. Экспорт содержит все записи |
| Сбой сохранения | Право записи в папку проекта. Переместить распакованную папку в доступный каталог |

## Данные между версиями

Существующие таблицы заявок и изменений сохраняются. Версия 2 при открытии создаёт две таблицы пакетов. Команда CLI допускает отдельную базу `--db`; это удобно для опытов и защиты. Команда и окно работают поверх одного класса Journal.
