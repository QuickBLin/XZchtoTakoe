# Происхождение данных и знаний

Корпус из 312 обращений специально составлен для учебного проекта с помощью ИИ. Реальная переписка организаций и реальные персональные данные источником не служили. Учебные тексты доступны в составе проекта. Структура, объёмы, подготовка, разделение и правила меток описаны в data/README.md.

Источниками постановки задачи и подхода служат требования к проекту, лекции курса ИИС и официальная документация scikit-learn 1.7.2. Каталог из шести тем сформирован как учебная модель внутренней ИТ-поддержки.

Словарь KEYWORDS и вопросы GUIDANCE являются авторскими учебными эвристиками, подготовленными в рамках проекта. Они выведены из описаний категорий и типовых симптомов. Специалисты конкретной службы поддержки их отдельно не валидировали. Для реального внедрения требуется согласование с её регламентами.

Масан Влад отвечает за подготовку и описание данных и правил разметки в подтверждённом распределении команды. Метки test и stress не подаются модели как входные признаки. Рабочие параметры после итогового stress не перенастраивались. Последующий анализ порогов носит диагностический характер.

Ограничения включают единый стиль искусственно составленных текстов, малый объём, возможное смысловое сходство примеров между частями и отсутствие независимой экспертной разметки.
