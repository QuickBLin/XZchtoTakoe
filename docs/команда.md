## Что показывает каждый на защите

Масан Влад объясняет разделение train/validation/test/stress, базовый словарь, TF-IDF, логистическую регрессию, метрики и два ошибочных случая. По запросу повторяет оценку на фиксированных данных.

Медведев Федор показывает ввод заявки, ручное назначение, карточку разбора, повтор CSV, отказ невалидного файла и сохранение после перезапуска. Объясняет транзакцию и одну интеграционную проверку.

Каждый участник должен уметь описать весь путь заявки и объяснить, почему система может ошибаться.

## История и подтверждение

Журнал TASKS.md фиксирует завершённые части по подтверждённому распределению. Фактические журналы испытаний подтверждают запуск проекта. Техническая история Git подготовлена от служебного автора Project scaffold и содержит версии комплекта. Она не используется для восстановления личной хронологии работы студентов.

Код и материалы подготовлены с помощью ИИ. Назначение участников — понимать принятые решения, проверять результаты и объяснять собственную часть.
